How this was made

Source: the public HN Algolia search API, phrase queries across 2007–today. A sentence counts as a request when it holds one of 20 buyer phrases and names a concrete thing (not “I'd pay for this”). Requests about software and products are embedded with bge-small and grouped by similarity; groups need 3+ different accounts. Matching is phrase-based, so some noise stays in. A comment is words, not a purchase. Code, raw method and data are open: GitHub · CSV · JSON · Hugging Face.
